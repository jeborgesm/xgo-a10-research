# XGO DY10 ↔ A10 direct-lineage investigation

Date: 2026-09-07

## Strongest new lead

The **XGO DY10** is much more important to A10 archaeology than the DY09.

Unlike DY09, DY10 is:
- a 10,000mAh XGO gaming power bank;
- transparent/cyberpunk horizontal enclosure;
- Linux-class according to Handhelds Wiki;
- marketed with the same 15W magnetic wireless / 22.5W wired charging combination;
- visually and functionally in the same product generation as the A10.

Current evidence strongly suggests DY10 is either:
1. the earlier retail/model designation for the same hardware family that became A10; or
2. an immediate predecessor/revision sharing the enclosure and Linux multi-emulator platform.

This is now a top-priority donor/ancestor target.

## Why this closely resembles our specimen

The crowdfunding-era feature set maps unusually well onto our A10:

| 2023 XGO campaign / DY10 family | Our A10 |
|---|---|
| 10000mAh | 10000mAh |
| 15W wireless | 15W wireless |
| 22.5W wired | 22.5W wired |
| transparent horizontal shell | same |
| TF card | same |
| TV output | same |
| external/controller support | same product claim and physical interface |
| 10 emulator families | same retail family; firmware confirms multi-system architecture |
| Linux | independently consistent with A10 |
| 6000+ games | later A10 retail bundles advertise up to 10000 |

The changing game-count claims (1000+, 6000+, 10000) are likely bundle/TF-content differences and should not be treated as hardware revisions by themselves.

## Critical hypothesis

**DY10 may be the missing direct retail ancestor of A10.**

This is substantially stronger than the DY09 comparison.

The naming chronology may reflect:
- DY10: original/early product designation;
- crowdfunding XGO: internationally marketed version, often without a visible model number;
- A10: later/current marketplace designation for the same or revised platform.

This is not yet proven. Proof requires one or more of:
- DY10 PCB photograph;
- DY10 firmware/SD image;
- DY10 user manual showing model label and filesystem behavior;
- exact enclosure dimensional comparison;
- a DY10 retail image exposing the same mainboard;
- firmware hashes or resource comparisons.

## Firmware search status

Targeted searches for:
- XGO DY10 firmware;
- 芯果 DY10 固件;
- DY10 TF card / SD image;
- DY10 HC15xx / SF2000;
- DY10 review/gameplay

have not yet produced a public firmware image.

However, the archived 2023 campaign explicitly stating **32GB TF** materially increases the likelihood that DY10 firmware/card contents once circulated as removable storage rather than sealed internal flash.

That makes used DY10 units and reseller card backups especially valuable.

## Search priorities

2. Find a DY10 stock TF-card image or downloadable firmware.
3. Find old AliExpress/Taobao/JD/Korean reseller photos that expose:
   - boot/menu UI;

   - packaging/manual;
   - model label;
   - controller/TV accessories.
4. Compare DY10 menu art against known A10 resources.
5. Determine whether Kickstarter-era 2023 unit already has the SF2000/DY19-family frontend.

## Evidence discipline

Until a firmware/PCB match is found:
- do not collapse DY10 and A10 into one model;
- do treat DY10 as the strongest current direct-lineage candidate;
- distinguish bundle/game-count changes from hardware changes;
- retain DY09 as manufacturer-family evidence only.
