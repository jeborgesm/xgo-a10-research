## Allocation policy

Reserve the cave as one owned module, not ad-hoc fragments:

```text
0x80A389B8  module entry / selector control
             navigation hooks

             renderer
             Refresh command dispatcher/adapters
```

The builder must fail closed if:
- baseline firmware SHA differs from Test106;
- any byte in the reserved source range is nonzero before patching;
- emitted module exceeds 0x840 bytes;
- any patch site does not match its expected original word(s).
