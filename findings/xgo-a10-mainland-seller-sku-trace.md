# XGO A10 mainland-China seller / SKU trace

Status: active exact-device archaeology
Date: 2026-09-13

This note records exact mainland-China retail/seller identifiers for the physical XGO A10 specimen. It is subordinate to `findings/hardware-firmware-lineage-matrix.md`; only exact-device evidence is accepted here.

## Confirmed exact A10 JD item

A surviving JD product page resolves the breadcrumb directly as:

```text
芯果 > 芯果A10
seller: 仓满数码店
JD item: 10162996228937
variant/title: 万款游戏-1万毫安快充 单机标配_中国大陆
```

The same page is titled as an XGO game-console power bank / magnetic fast-charge handheld and is categorized under game consoles.

Evidence level: **STRONG exact mainland retail provenance**.

Why this matters:
- `A10` is explicit in JD's own product breadcrumb, independently of export mirrors;
- `单机标配` establishes a mainland SKU distinction between standalone and controller-bundle configurations;
- this provides a concrete seller/item pair for after-sales, TF-card provisioning, archived questions, and replacement-card searches.

Do **not** infer that `单机标配` means no TF card. The item title also advertises `万款游戏`, so card/content inclusion remains unresolved unless package details or seller support material are recovered.

## Standalone vs dual-controller packaging

JD indexes separate exact-family package language including:

```text
单机标配
双人对战
尊享双人
```

An export image of the exact enclosure independently labels a controller bundle as `A10 (doubles)` / `Game handle` / `Ten thousand games` / `10000mAh`.

Interpretation: controller inclusion is a package/SKU variable. It should not be treated as evidence of a different motherboard or firmware without binary/PCB evidence.

## XGO card-provisioning practice — supporting context only

Current JD indexing for newer XGO handhelds explicitly exposes:

```text
无内存卡 ... 需自备卡下载游戏
32G
64G
128G
```

This is supporting evidence that XGO sells hardware and game-card content as separable provisioning tiers. Combined with the exact historical 1688 A10 option `A10（无卡无游戏）`, it strengthens the hypothesis that A10 replacement/original game cards may have circulated through seller after-sales rather than as conventional firmware downloads.

Do not project newer model card sizes directly onto A10 without exact bundle evidence.
