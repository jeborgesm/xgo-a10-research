# XGO Archaeology Image Corpus

## Workflow

`images/inbox/` is the drop zone for unclassified research photographs and screenshots.

Original uploaded files are preserved unchanged. Do not rename or overwrite inbox originals.

During review, significant images are cataloged by original path and Git blob SHA, classified by evidence type, and cross-linked from relevant findings. Descriptive archival copies may be added later when useful, but provenance always points back to the inbox original.

## Evidence labels

- **hardware evidence** — physical device, PCB, connectors, controls, ports, enclosure, accessories.
- **UI/runtime evidence** — firmware screens, menus, emulator output, test results, errors.
- **test setup** — wiring, controller, display, measurement or debugging arrangement.
- **reference/context** — useful context that does not independently prove a firmware/hardware claim.
- **uncertain** — interpretation requires corroboration before use as evidence.

## Cataloging rule

Image interpretation must distinguish what is directly visible from what is inferred. A photograph can corroborate a finding but does not override binary/source evidence for software behavior.
